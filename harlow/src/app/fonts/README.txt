Fonts loaded by next/font/local from this directory.

Cinzel, Crimson Pro, and Oswald are the Latin variable fonts from Google Fonts
(SIL Open Font License 1.1). One woff2 per style covers the weights the UI uses:
Cinzel 500-700, Oswald 300-700, Crimson Pro roman and italic 400-600.
See Cinzel-OFL.txt, CrimsonPro-OFL.txt, and Oswald-OFL.txt.

Special Elite is a static regular (weight 400) used for the stats index card.
Its name table licenses it under the Apache License 2.0, not the OFL.
See SpecialElite-LICENSE.txt.
